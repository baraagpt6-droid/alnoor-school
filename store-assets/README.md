# Alnoor School — Google Play store assets (2.0.4)

Package contents:
- icon-512.png — 512×512 PNG, fully opaque pixels with an alpha channel for Play icon compatibility.
- feature-graphic-1024x500.png — 1024×500 PNG, RGB/no alpha.
- screenshots/01-login.png — sign-in screen.
- screenshots/02-administrator.png — administrator portal.
- screenshots/03-teacher-lessons.png — teacher portal and lessons.
- screenshots/04-student-noor-assistant.png — student portal with Noor Assistant opened.
- APP-ACCESS-EN.md — reviewer sign-in instructions and reusable demo credentials.
- REVIEW-NOTES-EN.md — reviewer notes.
- STORE-LISTING-AR.md — Arabic store listing copy.
- UPLOAD-STEPS-AR.md — submission checklist.

The PNG screenshots are captured from the published 2.0.4 web app in a headless Chromium mobile viewport. They are converted to 1080×1920, 24-bit RGB PNG for Play Console.

Important: demo credentials are embedded in the public app as preview accounts. They are for synthetic test data only. Keep them separated from real student records. Do not claim student-data deletion is automatic: the account-deletion form currently records a request for administration review.

Source SVG files are retained alongside the PNG exports for future resizing.
