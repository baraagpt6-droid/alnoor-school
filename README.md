# مدرسة النور

منصة تعليمية تجريبية لمدرسة النور، بواجهة عربية من اليمين إلى اليسار ودعم تطبيق الويب التقدمي (PWA).

## أحدث إصدار
**1.1.2** — أضيف زر «تثبيت تطبيق مدرسة النور على الهاتف» في أعلى شاشة تسجيل الدخول وداخل الإعدادات. يستدعي الزر مطالبة التثبيت الأصلية عند دعم المتصفح لحدث `beforeinstallprompt`. كما تظهر إرشادات فتح الرابط في المتصفح عند اكتشاف متصفح داخلي مثل متصفحات التطبيقات.

## النشر
ينشر GitHub Actions الحزمة المرفقة بعد التحقق من بصمة SHA-256 وفحص سلامة ملف ZIP.

رابط الموقع: https://baraagpt6-droid.github.io/alnoor-school/

## حدود الاستخدام والأمان
هذه حزمة عرض وتجربة. تسجيل الدخول والأدوار والبيانات تُدار في الواجهة والمتصفح، ولا تمثل مصادقة أو صلاحيات آمنة على خادم. لا تستخدمها لحفظ بيانات طلاب حقيقية أو كلمات مرور أو سجلات مدرسية خاصة. لا تضع مفاتيح خدمات الذكاء الاصطناعي في الملفات العامة أو الشيفرة الأمامية. بيانات المنهج المرفقة أمثلة أولية وتحتاج مراجعة واعتماد المدرسة.

راجع `SECURITY_REVIEW_AR.md` و`madrasti_security_review.md` قبل أي استخدام فعلي.
