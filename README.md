# مدرسة النور

منصة تعليمية تجريبية لمدرسة النور، مبنية كتطبيق ويب تقدمي (PWA) بواجهة عربية من اليمين إلى اليسار.

## الملفات
- `index.html` واجهة التطبيق.
- `styles.fixed.css` تنسيقات الواجهة.
- `curriculum.json` بيانات منهج تجريبية للمراجعة.
- `manifest.json` إعدادات تثبيت التطبيق.
- `sw.js` دعم التخزين والعمل دون اتصال.
- `.github/workflows/deploy.yml` النشر التلقائي إلى GitHub Pages عند الدفع إلى `main`.

## النشر
من إعدادات المستودع، اختر **Settings → Pages** واجعل مصدر النشر **GitHub Actions**. سير العمل الموجود في `.github/workflows/deploy.yml` ينشر الموقع عند كل تحديث لفرع `main`.

## تنبيه أمني مهم
هذه حزمة عرض وتجربة. تسجيل الدخول والأدوار والبيانات تُدار في الواجهة والمتصفح، ولا تمثل مصادقة أو صلاحيات آمنة على خادم. لا تستخدمها لحفظ بيانات طلاب حقيقية أو كلمات مرور أو سجلات مدرسية خاصة. مفاتيح خدمات الذكاء الاصطناعي لا ينبغي وضعها في ملفات عامة أو تضمينها في الشيفرة الأمامية. وحدات المنهج المرفقة أمثلة أولية وتحتاج مراجعة واعتماد المدرسة.

راجع `SECURITY_REVIEW_AR.md` و`madrasti_security_review.md` قبل أي استخدام فعلي.
