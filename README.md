# مدرسة النور — الإصدار 1.3.0

منصة تعليمية عربية تجريبية تدعم تطبيق الويب التقدمي (PWA) وتطبيق Android المبني على WebView.

## ما الجديد في 1.3.0

- مساعد نور يحاول الاتصال بخدمة Pollinations النصية العامة دون تضمين مفتاح في التطبيق، ويمكن توجيهه اختيارياً إلى رابط وسيط HTTPS مع حفظ أسرار Gemini أو Groq في الخادم الوسيط فقط.
- عند تعذر الاتصال الخارجي، يرجع المساعد إلى محتوى الدروس والواجبات والحضور والجداول المحفوظة على الجهاز.
- بوابة المعلم منظمة إلى الدروس والمختبر، الحضور السريع، الواجبات والدرجات، وجدول الحصص.
- بوابة ولي الأمر تعرض ملخص الطالب مع تبويبات الدرجات والحضور والجدول والواجبات والتواصل.
- بوابة المشرف العام تعرض الإحصائيات والطلاب والتسجيل والصفوف والرسائل، مع الرد على الرسائل وتصدير CSV والطباعة.
- تحسين محاذاة شاشة البداية في Android وإزالة شاشة HTML المكررة.
- إصدار Android: `versionCode 130` و`versionName 1.3.0`.

## حسابات العرض التجريبية

| البوابة | المعرّف | الرمز أو كلمة المرور |
|---|---|---|
| الطالب | `ST-101` | `1234` |
| ولي الأمر | `ST-101` | `771001100` |
| المعلم | `TCH-01` | `1111` |
| الإدارة | `ADM-01` | `0000` |

هذه الحسابات بيانات علنية للعرض فقط.

## النشر والتوقيع

ينشر GitHub Actions الموقع على GitHub Pages ويبني APK موقّعاً باستخدام أسرار المستودع:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

لا تحفظ ملف JKS أو كلمات المرور داخل المستودع. حافظ على ملف JKS الرسمي نفسه لكل تحديث حتى يبقى APK قابلاً للتحديث فوق النسخ السابقة.

الموقع: https://baraagpt6-droid.github.io/alnoor-school/

## حدود الاستخدام والأمان

**هذا الإصدار ما زال نموذجاً تجريبياً محلياً، وليس نظام إدارة مدرسة إنتاجياً متعدد المستخدمين.**

- بيانات الطلاب والدرجات والحضور والواجبات والجداول والرسائل تُحفظ في `localStorage` على الجهاز أو المتصفح الحالي. لا يوجد خادم مدرسي أو قاعدة بيانات مركزية أو مزامنة بين الأجهزة.
- تسجيل الدخول والأدوار التجريبية تنفذ في الواجهة ولا تمثل مصادقة خادمية آمنة. لا تستخدم الحسابات التجريبية أو هذا الإصدار لحفظ بيانات طلاب حقيقية أو سجلات خاصة.
- تقرير CSV يعرض البيانات الموجودة محلياً على الجهاز الذي يصدره فقط.
- اتصال Pollinations العام يعتمد على نقطة نهاية عامة قد تتوقف أو تفرض حدود استخدام أو تتغير. لا يمكن ضمان عمله مدى الحياة أو توفير خدمة بلا انقطاع. عند الفشل يحاول المساعد استخدام البيانات المحلية.
- رابط الوسيط الاختياري يرسل السؤال وسياق البوابة والدرس إلى الخادم الذي تحدده. احفظ أي مفتاح خدمة في أسرار الخادم الوسيط، ولا ترسل أسماء الطلاب أو أرقامهم أو درجاتهم أو بياناتهم الشخصية إلى خدمات عامة.
- يجب مراجعة بيانات المنهج والأمثلة التعليمية واعتمادها من المدرسة قبل استخدامها تعليمياً.

قبل استخدام بيانات حقيقية، أضف خادماً موثوقاً مع مصادقة وصلاحيات لكل دور وقاعدة بيانات مشفرة ونسخ احتياطي وسجل تدقيق وسياسة خصوصية وموافقة مناسبة من أولياء الأمور.
