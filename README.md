# مدرسة النور

منصة تعليمية تجريبية لمدرسة النور، بواجهة عربية من اليمين إلى اليسار ودعم تطبيق الويب التقدمي (PWA).

## أحدث إصدار — 1.1.3
- تعبئة بيانات الدخول التجريبية تلقائيًا عند فتح شاشة تسجيل الدخول أو تغيير البوابة.
- زر «دخول تجريبي سريع بضغطة واحدة» لكل بوابة.
- يمكن تعديل حقول الدخول يدويًا قبل تسجيل الدخول.

حسابات العرض:
| البوابة | المعرّف | الرمز أو كلمة المرور |
|---|---|---|
| الطالب | `ST-101` | `1234` |
| ولي الأمر | `ST-101` | `771001100` |
| المعلم | `TCH-01` | `1111` |
| الإدارة | `ADM-01` | `0000` |

## النشر
ينشر GitHub Actions الحزمة المرفقة بعد التحقق من بصمة SHA-256 وفحص سلامة ملف ZIP.

رابط الموقع: https://baraagpt6-droid.github.io/alnoor-school/

## حدود الاستخدام والأمان
هذه حزمة عرض وتجربة. تسجيل الدخول والأدوار والبيانات تُدار في الواجهة والمتصفح، ولا تمثل مصادقة أو صلاحيات آمنة على خادم. بيانات الدخول التجريبية علنية ومخصصة للعرض فقط. لا تستخدمها لحفظ بيانات طلاب حقيقية أو كلمات مرور أو سجلات مدرسية خاصة. لا تضع مفاتيح خدمات الذكاء الاصطناعي في الملفات العامة أو الشيفرة الأمامية. بيانات المنهج المرفقة أمثلة أولية وتحتاج مراجعة واعتماد المدرسة.

راجع `SECURITY_REVIEW_AR.md` و`madrasti_security_review.md` قبل أي استخدام فعلي.
